Owlbear Rodeo extension

A Link to the Paste

Paste copied Owlbear Rodeo items with extra control, directly from the context menu. Decide what changes and what stays untouched before items return to your scene.

View on GitHub

Paste with intent

#
Fresh IDs
Generate new identifiers and preserve attachment links between copied items.
◉
Ownership
Take ownership of every pasted item when reusing content from another player or room.
⌖
Position
Bring pasted items to the center of your current viewport instead of their saved coordinates.
◐
Visibility
Make all pasted items visible, hidden, or leave their existing visibility unchanged.

Install

  1. Copy the manifest URL https://alinktothepaste.onrender.com/manifest.json
  2. Open your Owlbear Rodeo profile Go to Extensions, choose Add Extension, then select the option to install from a manifest.
  3. Paste the URL and install Enable the extension for the room where you want to use the special paste menu.
The extension requests clipboard-read permission so it can read the Owlbear Rodeo item data you have explicitly copied.

How to use it

1

Copy

Select one or more items in Owlbear Rodeo and copy them as usual.

2

Open the menu

Open the scene context menu with no item selected and choose Special Paste.

3

Choose

Set the ID, ownership, position and visibility behavior you need.

4

Paste

Press Paste. A notification confirms how many items were added.

Paste options

IDNew / No change

New assigns a new unique ID to every pasted item. Internal attachment references are updated with the new IDs. No change retains the copied identifiers.

OwnershipTake / No change

Take makes you the creator of every pasted item. No change keeps existing owners and only fills in missing ownership information.

PositionHere / No change

Here moves the pasted items to the center of your current view. No change preserves their copied positions.

VisibleYes / No / No change

Force every pasted item to be visible or hidden, or retain the visibility stored in the copied data.

No change is the default for every option, so opening the tool and immediately pressing Paste keeps the copied data as close to its original state as possible.

Clipboard and privacy

⌘

Processed in your browser

The extension reads clipboard text only when you submit the paste form. It parses the copied JSON locally, applies your selected transformations, and adds the resulting items to the current Owlbear Rodeo scene.

No account, API key or remote storage is required by the paste workflow.
