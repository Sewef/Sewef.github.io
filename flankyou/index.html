Flank You

Automatic flanking detection for PTU 1.05 and D&D 5e 2014. Assign teams, move your tokens, and see vulnerable creatures marked directly on the map.

Install

  1. Copy the manifest URL https://flankyou.onrender.com/manifest.json
  2. Open Owlbear Rodeo Extensions From your profile, choose to add an extension using a manifest URL.
  3. Install and enable Flank You Add it to the room, open a scene, then launch it from the action bar.

Set up a combat

1

Choose rules

Select PTU 1.05 or D&D 5e 2014 for the room.

2

Assign teams

Use the panel or token context menu to group allies together.

3

Set exceptions

Mark immune creatures and decide whether mounts can flank.

4

Play

Move tokens normally; the overview and map markers update the result.

Tokens on the same team are allies. Tokens assigned to different teams are treated as enemies for flanking calculations.

Supported rulesets

PTU 1.05

Contact-based flanking

Flank You evaluates enemies occupying cells adjacent to the target. The number of required contact cells scales with the target’s longest side, supporting creatures from 1×1 through 4×4.

A valid flank requires at least two usable enemies and enough combined contact around the target.

D&D 5e 2014

Opposite-side flanking

Two allied attackers must threaten the target from opposite regions around its occupied space.

Flanking is an optional rule in D&D 5e 2014. Enable and use this ruleset only when it is part of your table’s rules.

Panel and token controls

ControlWhat it does
RefreshForces the token overview and flanking state to be recalculated.
HitboxesToggles colored outlines matching each token’s assigned team.
Mounts can flankIncludes mounted creatures among eligible flank participants.
RulesSwitches the room between PTU 1.05 and D&D 5e 2014 calculations.
Team tabsFilters the compact overview and displays the number of tokens in each team.
ImmunePrevents an individual token from ever receiving the flanked state.

Context menu

Select one or more tokens and open the Flank You context menu to assign the whole selection to a team or change its immunity. The same values can be edited token by token from the extension panel.
