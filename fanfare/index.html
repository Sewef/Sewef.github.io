Fanfare

Turn the end of an encounter into an event. Broadcast animated XP progression and rarity-styled loot to every player, with a preview before the big reveal.

View on GitHub

Configure rewards in the GM panel, then reveal them in a theme-aware popover for everyone at the table.

Install

  1. Copy the manifest URL https://fanfare.onrender.com/manifest.json
  2. Open Owlbear Rodeo Extensions From your profile, choose to add an extension from a manifest URL.
  3. Install and enable Fanfare Add it to your room, then open Fanfare from the action bar as a GM.

XP bars

Add as many progression bars as your reward needs. Each bar can carry its own label and can be enabled or disabled before sending.

Party experience +35%
75%
FieldPurpose
LabelIdentifies the progression represented by this bar.
Max XPDefines the total value used to calculate the displayed percentage.
CurrentThe starting value, shown before the fill animation progresses.
NewThe resulting value after the reward has been applied.
The player popover animates the progression over roughly two seconds and shows the difference between the old and new values.

Loot and rarity

Every loot entry has a name, a quantity, and one of five rarity levels. Rarity controls the border, color, and glow used during the reveal.

CommonBasic items
UncommonNotable finds
RarePowerful rewards
Very RareExceptional loot
LegendaryMythic treasures

JSON format

Export a loot list for reuse or import an existing list with this structure:

[
  {
    "name": "Dragon Scale",
    "quantity": 5,
    "rarity": "uncommon"
  },
  {
    "name": "Dragon's Heart",
    "quantity": 1,
    "rarity": "legendary"
  }
]
Use Demo to populate a sample list instantly, then Export to inspect or copy the exact JSON.

Preview, save, and reuse

Preview

Opens the reward presentation only on your own screen. Players receive nothing until you press Send.

Scene

Saves the complete setup to the current scene metadata. Use this for rewards tied to a particular map or encounter.

Room

Saves the setup to room metadata so it remains available when moving between scenes.

Enable Auto save on send to update the selected save target each time a reward is broadcast.
